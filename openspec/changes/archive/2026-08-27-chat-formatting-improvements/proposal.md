# Change Proposal: Chat Formatting Improvements & Markdown Typography Rendering

**Change Name**: `chat-formatting-improvements`  
**Date**: 2026-08-27  
**Author**: SDD Team  
**Status**: Completed  

---

## 1. Problem Statement
The WebMCP Copilot chat drawer previously rendered raw assistant response strings directly or with partial markdown escaping. This led to multiple UX and formatting issues:
1. **Raw Hash Headers**: Headings generated by LLMs (`#`, `##`, `###`) were displayed as raw unstyled hashtag text (e.g. `### Step 1: Initialize Scene`), creating a raw, unpolished developer look.
2. **Missing Code Block Styling**: Inline code (\`const x = 1;\`) and multiline fenced code blocks (\`\`\`typescript ... \`\`\`) were not styled with dark monospaced code containers.
3. **List Formatting**: Numbered and bulleted lists were displayed as plain multiline text instead of indented HTML list structures.
4. **Robotic Model Tone**: The dynamic system prompt lacked specific operational directives discouraging robotic markdown walls and heavy header usage.
5. **Contextual Quick Chips**: Prompt chips were static across different views rather than dynamically aligning with active view domains.

---

## 2. Proposed Solution
1. **Robust Markdown Parser & Formatter (`formatMessageContent`)**:
   - Safely escape raw HTML (`<`, `>`, `&`, `"`) to prevent XSS.
   - Extract and protect fenced code blocks and inline code before formatting.
   - Strip raw `#` characters from headings and transform them into clean typography `<div>` containers.
   - Convert bullet (`- `, `* `) and numbered (`1. `) lists into semantic `<ul>` and `<ol>` HTML elements.
   - Convert bold (`**` / `__`) and italic (`*` / `_`) tokens.
   - Reinsert protected code blocks in dark syntax-highlighted containers.
2. **Conversational Directives in System Prompt**:
   - Instruct the Copilot to adopt a natural, fluid conversational tone and avoid excessive markdown headers.
3. **Contextual Quick Prompt Chips**:
   - Dynamically compute prompt chips matching the active view (Showroom 3D, Enterprise BI, Judge Guide, Inspector).

---

## 3. Scope & Impact
- **Modified Components**: `CopilotChatComponent`, `CopilotBridgeService`.
- **Modified Models / Types**: `copilot-bridge.types.ts`.
- **Unit Test Coverage**: Comprehensive unit tests covering XSS safety, header stripping, list nesting, code block extraction, and system prompt formatting directives.
